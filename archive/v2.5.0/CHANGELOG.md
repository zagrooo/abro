## فروشگاه آزمایشی

قبلاً تپ روی بسته فقط یک پیام «وصل نیست» می‌داد. حالا خرید کامل کار می‌کند:

```
تپ روی بسته → کارت تأیید (محتوا + قیمت + برچسب آزمایشی) → تأیید → جنس می‌رسد
```

**برچسب «حالت آزمایشی» همیشه دیده می‌شود** — هم بالای فروشگاه، هم روی کارت تأیید.
دلیلش این است که اگر این نسخه دست کسی بیفتد، نباید فکر کند پول واقعی داده.

### لایه‌ی پرداخت جدا شد

فایل تازه‌ی `js/billing.js` تنها جایی است که روز وصل کردن بازار عوض می‌شود:

```js
var MODE = 'test';        // → 'bazaar'
var SKU_MAP = { g1: 'abroo_gems_50', ... };
function realBuy(item, onOk, onCancel) { /* اینجا Poolakey */ }
```

بقیه‌ی بازی هیچ خبری از این تغییر ندارد. `game.js` فقط `A.billing.buy()` را
صدا می‌زند و منتظر جواب می‌ماند.

## بسته‌های فیروزه — پنج پله

| بسته | فیروزه | قیمت | هر فیروزه |
|---|---|---|---|
| مشت | ۵۰ | ۲۹٬۰۰۰ | ۵۸۰ |
| کیسه | ۱۲۰ | ۵۹٬۰۰۰ | ۴۹۲ |
| صندوق | ۳۲۰ | ۱۴۹٬۰۰۰ | ۴۶۶ |

اگر روزی قیمتی را دستی عوض کنی و این نظم بشکند، تست می‌گیردش.

## بسته‌های ویژه — تازه

ترکیبی، با شرط نمایش. فقط آن‌هایی دیده می‌شوند که به درد پرده‌ی فعلی می‌خورند.

| بسته | داخلش | قیمت | شرط |
|---|---|---|---|
| **بسته‌ی شروع** | ۸۰ فیروزه + ۲ ساعت درآمد + ۱ نیروی ماهر | ۴۹٬۰۰۰ | تا پرده‌ی ۴، یک‌بار |
| **بسته‌ی رشد** | ۲۵۰ فیروزه + ۶ ساعت درآمد + ۱۰ جای دائمی | ۱۹۹٬۰۰۰ | از پرده‌ی ۴، یک‌بار |
| **بسته‌ی استاد** | ۷۰۰ فیروزه + نیروی استاد + ۳ آبرو | ۴۹۹٬۰۰۰ | از پرده‌ی ۸، یک‌بار |
| **صندوق روزانه** | روزی ۲۰ فیروزه، ۳۰ روز | ۱۴۹٬۰۰۰ | اشتراک |
| **حذف تبلیغ** | تبلیغ اجباری حذف + ۴۰ فیروزه | ۹۹٬۰۰۰ | یک‌بار |

بسته‌های یک‌باره بعد از خرید از فروشگاه ناپدید می‌شوند.

### حذف تبلیغ منصفانه است

با خریدنش، **جایزه‌های تبلیغ از بین نمی‌روند** — فقط دیگر تبلیغ نمی‌بینی و
همان جایزه را رایگان می‌گیری. دکمه‌اش می‌شود «جایزه‌ی روزانه».

### صندوق روزانه

تا وقتی اشتراک فعال است، هر روز یک بار ۲۰ فیروزه. کارتش بالای فروشگاه
می‌نشیند و وقتی آماده است نبض می‌زند. روزی که بگیری قفل می‌شود تا فردا.

## تست

**۶۸۵ بررسی، صفر مردود** (۶۲ تای تازه برای فروشگاه):

- یکتایی شناسه‌ها بین بسته‌های فیروزه و ویژه
- صعودی بودن فیروزه و **نزولی بودن قیمت هر واحد**
- شناخته‌شده بودن هر کلید محتوا (اگر کلید ناشناسی بنویسی، تست می‌گیرد)
- شرط پرده: بسته‌ی شروع در پرده‌ی ۹ نباید دیده شود، بسته‌ی استاد در پرده‌ی ۱
- ناپدید شدن بسته‌ی یک‌باره بعد از خرید
- صندوق روزانه: یک بار در روز، نه دو بار
- ماندن سابقه‌ی خرید و اشتراک و حذف تبلیغ بعد از بارگذاری ذخیره

تست کش‌شکن هم هوشمند شد: به‌جای عدد ثابت، **هر دارایی css و js** را بررسی
می‌کند و مطمئن می‌شود فایلی که در HTML صدا زده شده واقعاً وجود دارد.
